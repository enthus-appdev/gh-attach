# Badges

This is an orphan branch that stores the coverage badge SVG published by
[`.github/workflows/go.yml`](../../blob/main/.github/workflows/go.yml) via
the [`vladopajic/go-test-coverage`](https://github.com/vladopajic/go-test-coverage)
action.

The badge lives at `.badges/main/coverage.svg` and is updated on every
successful main run. This branch has **no common ancestor with `main`** and
must never be merged into it.
